# Python-8 

A Chip-8 emulator in Python using the pygame and numpy external libraries

## Overview

Python-8 is a CHIP-8 emulator written in Python that allows for users to execute CHIP-8 ROMs in a user-friendly GUI environment. There are various comfort features included such as variable clock speeds, dynamic window resizing and save states.

## Features

- **Plays Most CHIP-8 ROMs**: Python-8 can play most ROMs perfectly, with more compatibility to come in the future. 

- **Interactive Environment**: Execute ROMs with ease using Python-8's interactive features such as dynamic resizing.  

- **Error Handling**: Catches most errors and will display the relevant information.

## Requirements

- Python 3.0 or above.
- The `pygame` and `numpy` external libraries are required, these can be installed via pip.

## Downloading & Installation

Simply clone or download the repository and run the `python-8.py` file.

```bash
git clone https://github.com/0x8192/Python-8.git
cd Python-8
python python-8.py
```

## Usage

1. Run the Python script `python-8.py` in your terminal or file explorer.
2. Select your desired ROM to execute.
3. Enjoy!
